# Example outputs

- `reconciliation_report_clean.xlsx` demonstrates a successful run with no
  genuine issues.
- `reconciliation_report_test_cases.xlsx` demonstrates the error statuses
  produced by the deliberately defective destination.
- `lop_sample_data.xlsx` is the original LOP reference sheet. Its values are
  already merged into `sample_data/source_salary.xlsx`.

Generated reports are ignored by default. Keep these examples only when their
results are intentionally updated together with the sample data and rules.
