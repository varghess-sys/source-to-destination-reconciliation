# Sample data folder

This folder contains the fictional demonstration files:

- `source_hr.csv`
- `source_legacy.xml`
- `source_notepad.txt`
- `source_salary.xlsx`
- `source_bonus.txt`
- `source_performance.csv`
- `destination.csv`
- `destination_test_cases.csv`

`destination.csv` is the clean transformed sample. Use
`destination_test_cases.csv` only with `config_test_cases.json` when testing
the error-reporting paths. Monthly LOP values are already present in
`source_salary.xlsx`.

Do not place real employee or payroll information in Git.
